# W4 · KnowledgeVault

## What it is
KnowledgeVault ingests engineering PDFs and indexes their prose, figures and tables. It returns ranked chunks, including figure descriptions with an image link; it does not generate answers.

## How it works
- Ingestion runs five stages via `python -m app.ingest --pdf ...` or `POST /ingest` / `POST /ingest/all`: parse, describe figures, chunk, embed, index.
- `parse_pdf` uses PyMuPDF for text blocks and figure crops and pdfplumber for tables.
- Figures go to `gpt-5.4-mini-2026-03-17` as base64 images with `tool_choice` forcing `record_figure_description` (strict schema). It is validated as `FigureDescription` (`type`, `summary`, `key_elements`, `confidence` high/medium/low); low-confidence descriptions are dropped by default.
- Chunking: prose in 300-token children with 50-token overlap (tiktoken `cl100k_base`), each tagged with the `parent_id` of its 1,500-token parent span; one chunk per figure description; one chunk per table row as `header: value | ...`.
- `text-embedding-3-large` (3,072 dims) with a SHA-256 text cache; Qdrant collection with one 3,072-dim cosine vector, point ids `uuid5(chunk_id)`, upserts in batches of 100.
- `POST /retrieve` (default `k=5`) fuses dense Qdrant search (`k*3` candidates) with in-memory BM25Okapi over up to 10,000 scrolled points, using reciprocal rank fusion with `k=60`.

## Key decisions
- **Embed children only** - 300-token children retrieve sharply, while the 1,500-token parent is an id to regroup context without doubling the index or the embedding bill.
- **RRF over weighted score fusion** - dense and BM25 scores live on different scales; rank fusion needs no normalisation.
- **Forced function calling for vision** - the model cannot answer in prose, so every figure yields a validated object.
- **One provider for vision and embeddings** - one API key; the configured `gpt-5.4-nano-2026-03-17` fast model is only reported by `/health`.
- **Lazy imports in route handlers** - `/health` stays up if heavy pipeline dependencies fail to load.

## Results
- No scored retrieval set this week (no recall gate, score threshold or refusal); 7 offline smoke tests in `tests/test_endpoint.py` pass.
- A diagram query ranks the page-4 figure description first (RRF 0.0323, k=5).
- Sample corpus: `data/sample/attention-is-all-you-need.pdf` (15 pages), with 2 extracted figures in `data/figures/`.

## Stack
Python, FastAPI 0.115.6, OpenAI SDK 2.14.0 with `gpt-5.4-mini-2026-03-17` (vision) and `text-embedding-3-large`, Qdrant (qdrant-client 1.12.1), PyMuPDF, pdfplumber, rank-bm25, tiktoken, Pydantic 2.10.4.
