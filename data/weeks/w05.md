# W5 · CitationRAG

## What it is
CitationRAG is a FastAPI service that answers questions about the "Attention Is All You Need" paper from a Qdrant index and backs every claim with an inline `[doc#N]` citation and a verbatim supporting quote. It is for readers who need to check where an answer came from: when retrieval is weak, it refuses with one exact sentence instead of guessing.

## How it works
- `POST /answer` runs four steps: retrieve, threshold gate, generate, validate.
- Retrieval reuses the Week 4 `knowledgevault` collection: dense search with `text-embedding-3-large` plus in-memory BM25Okapi, fused with Reciprocal Rank Fusion (k = 60); the top 5 chunks are renumbered `doc#1` to `doc#5`.
- The gate reads the raw dense cosine, not the RRF score: no model call unless top-1 >= 0.55 and top-1 minus top-3 >= 0.08.
- `gpt-5.4-mini-2026-03-17` answers in JSON mode (`answer`, `citations` with `chunk_id` and `supporting_quote`); malformed JSON becomes a refusal.
- `app/citations.py` checks that every cited ID was actually sent and every quote appears verbatim (case-insensitive) in its chunk; a failure becomes a refusal with `refusal_source` = `validation` (others: `threshold_gate`, `llm`).
- `POST /eval` reports groundedness, citation precision, citation recall, false-answer rate and false-refusal rate.

## Key decisions
- **Deterministic citation checks, not an LLM judge** - free, instant and unable to hallucinate; a paraphrased quote fails.
- **One byte-identical refusal string** ("I don't have that information in the provided sources.") - shared by prompt, eval and tests, so a correct refusal is never scored as a wrong answer.
- **Refuse on validation failure** - a fabricated source is worse than no answer; this gives up some recall.
- **RRF instead of score blending** - dense and BM25 scores live on incompatible scales; ranks combine without calibration.

## Results
- No recorded eval run: `POST /eval` scores the 10-row golden set in `data/golden_dataset.json` (8 answerable, 2 must-refuse) on the five metrics with deterministic proxies (token overlap, ID and set checks); no metric output is saved in the package.
- README states the 0.55 / 0.08 thresholds were calibrated against real `text-embedding-3-large` scores; no committed calibration run found.
- `tests/test_endpoint.py`: 4 offline smoke tests (health, grounded answer, below-threshold refusal, fabricated `[doc#99]` caught).

## Stack
Python, FastAPI, pydantic-settings, OpenAI SDK (`gpt-5.4-mini-2026-03-17`, `text-embedding-3-large`), qdrant-client, rank-bm25, pytest.
