# W17 · Demo Day + PortfolioAgent

## What it is
The capstone's public front door: a small agent that answers a visitor's questions about what was built each week, its results and its design, on one shareable URL. A hiring manager can scroll the build cards, ask the agent, ask a follow-up, or ask to get in touch - and another agent can call it over A2A.

## How it works
- A deterministic classifier picks the tier: short lookups run on gpt-5.4-nano, questions with a reasoning cue on gpt-5.4-mini; a long cue-free question is routed up below 0.60 confidence.
- That model runs a function-calling loop over five tools: get_build, get_week_details, get_eval_results, get_architecture (by section or by week) and request_intro.
- Every read tool returns a source tag such as [AGENTS.md · W4]; code checks each citation in the answer against the sources returned in that run, and only then marks it grounded.
- The browser keeps the last three turns and sends them with each question; the server stores no conversation.
- request_intro creates an action at input-required; only the student, with the admin token, approves it through POST /approve.
- A2A 1.0: an Agent Card at /.well-known/agent-card.json, signed (detached JWS, ES256, key at /.well-known/jwks.json), and JSON-RPC SendMessage at /a2a, answered by the same loop as POST /ask. The owner decides intro requests on /admin.

## Key decisions
- **Tools instead of the whole pack in the prompt** - the model cites what it looked up, and the first call is about 1,200 input tokens instead of about 5,500.
- **The tier is code, the tools are the model's** - routing stays reproducible and free; choosing which week to read is the model's job, and the tool-choice gate measures it.
- **Citations checked by code** - a source no tool returned in this run makes the answer ungrounded.
- **Caps across the loop** - the $0.05 ceiling is checked before every call against what the loop already spent; eight calls at most (429).
- **Approval is server state** - no sentence from the visitor or the model can approve an intro.

## Results
- Routing gate: 27 frozen questions, 0.963 accuracy (26 of 27), 19 small / 8 frontier; on first-call tokens the routed bill is $0.020055 against $0.039622 all-frontier, 1.98x cheaper (`data/eval_results.json`, written by `eval_run.py`).
- Tool-choice gate: 14 frozen questions against the live model, floor 0.80 (`eval_tools.py --live`).

## Stack
Python 3.12, FastAPI, Pydantic, the OpenAI SDK (gpt-5.4-nano-2026-03-17, gpt-5.4-mini-2026-03-17), tiktoken (o200k), tenacity; deployed on Render from GitHub.
