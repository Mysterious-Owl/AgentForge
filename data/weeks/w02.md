# W2 · IntentIQ

## What it is
IntentIQ classifies a customer message into one of four intents (`cancel_subscription`, `request_refund`, `payment_question`, `unknown`) and benchmarks three model tiers on the same hand-labelled set. It picks a model by measuring accuracy, tail latency and cost together.

## How it works
- A provider abstraction in `app/llm.py`: `classify(provider, text)` dispatches to `openai` (gpt-5.4-mini), `nano` (gpt-5.4-nano) or `ollama` (local qwen3:0.6b); all three use the OpenAI SDK, Ollama via its OpenAI-compatible endpoint at `localhost:11434/v1`.
- Every adapter returns one `Result` shape: label, confidence (Pydantic-bounded 0.0-1.0), latency_ms, input/output tokens.
- `normalise_label()` maps case and spacing drift to a valid label or `unknown`; `_safe_json()` tries strict JSON, then a fenced block, then a bare `{...}`.
- The qwen3 adapter disables thinking (`think: False`), allows `max_tokens=400`, and falls back to the reasoning field if content is empty.
- `golden_dataset.jsonl` holds 30 rows (8 cancel, 8 refund, 9 payment, 5 unknown). `app/eval.py` computes accuracy, p50, p95 and cost per 1,000 calls, and logs a failed row instead of crashing.
- Entry points: `POST /classify`, `POST /benchmark`, `GET /benchmark-stream` (SSE progress), and the CLI `python -m app.main benchmark`.

## Key decisions
- **Dated model pins** - `gpt-5.4-mini-2026-03-17` and `gpt-5.4-nano-2026-03-17`, so an upgrade becomes a re-run against both pins, not silent drift.
- **One SDK for three backends** - only the client config differs; local-model quirks need adapter-side defences.
- **Rate-limit retry inside the latency timer** - one retry after 0.5 s, counted in `latency_ms` so the reported latency is honest.
- **Pricing table in code** - mini $0.75/$4.50, nano $0.20/$1.25 per 1M input/output tokens, Ollama $0.

## Results
- On the 30-row golden set: nano 93.3% (p95 1,185 ms, $0.0354 per 1K calls), mini 90.0% (p95 4,665 ms, $0.1293 per 1K), qwen3:0.6b 66.7%.
- An earlier run tied mini and nano at 90.0%.
- One row is 3.3 points on this set, so a one-row accuracy gap is noise; the tail-latency and cost gaps are signal. Measure accuracy and tail latency together, and expect run-to-run variance.

## Stack
Python, FastAPI, OpenAI SDK with `gpt-5.4-mini-2026-03-17` and `gpt-5.4-nano-2026-03-17`, Ollama `qwen3:0.6b`, Pydantic, pydantic-settings, pytest.
