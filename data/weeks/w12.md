# W12 · GuardianAI™

## What it is
GuardianAI™ is a hardening layer on top of a citation-based RAG service. It defends against prompt injection, scrubs personal data before it is stored or shown, limits which documents each role can see, and writes an append-only audit log, so the assistant can be trusted with sensitive internal documents.

## How it works
- `POST /ask` runs: Presidio input scrub, a regex injection classifier (refuses and audits when flagged), hybrid retrieval, a read-time sanitiser that strips instruction-shaped sentences from chunks, citation frames, then streamed tokens.
- Retrieval is Qdrant dense search with `text-embedding-3-large` (3072-dim) plus BM25, fused with RRF (k=60); a 0.55 cosine floor decides membership.
- Each chunk carries a `visible_to` ACL that is pushed into both the dense and BM25 channels; `@requires_role("analyst")` guards the routes, so a viewer gets 403.
- Ingestion (`python -m app.ingest`, `POST /ingest/text`, `POST /ingest/file`) is chunk, scrub, embed, upsert; the seed corpus is 20 chunks.
- Output is scrubbed through a 280-character sentence buffer before each SSE frame.
- The audit log is JSONL with salted SHA-256 user ids and never a raw value in `detail`.

## Key decisions
- **Scrub at ingestion, not retrieval** - otherwise the store itself becomes a PII database; the injection sanitiser stays on the read path.
- **Visible `<REDACTED>`** - Presidio's `replace` operator instead of `redact`, so redactions are legible.
- **Thresholds** - redact at >= 0.65, human-review queue for 0.35-0.65; the phone recogniser is re-scored from 0.40 to 0.85 so numbers are actually redacted.
- **RBAC decorator plus ACL filter** - a spoofed role passes the decorator but still cannot retrieve hidden chunks.
- **Boot fails if Presidio is degraded** - `startup_check()` crashes on a missing spaCy model rather than scrubbing silently without NLP recognisers.

## Results
- `POST /eval` on the 12-row golden set (6 answer, 2 refuse, 2 injection_refusal, 2 acl_block) through the live pipeline with `gpt-5.4-mini-2026-03-17`: accuracy 1.0 (12/12), PII leaks 0 (must be 0), recorded in `week12_notebook.ipynb` output.
- README records `python -m app.ingest --reset` as "ingested 20 chunks · 6 PII spans redacted"; no committed log of that run found.
- No recorded test run: `tests/test_endpoint.py` holds 16 offline tests.

## Stack
